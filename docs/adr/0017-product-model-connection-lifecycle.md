# ADR-0017：产品内模型连接版本与受控启用

状态：已接受（维护者于 2026-09-12 在 EXP-UX-01 完成后的会话批准按本轮规划继续 EXP-UX-02 的 Spec/ADR 定稿及正式任务衔接；具体运行时方案仍受下述隔离证据门禁约束）。

## 决策与范围

依据 [Release 1 Spec 的 EXP-UX-02](../specs/asset-governance-release-1.md#exp-ux-02-产品模型连接的安全版本与实际启用)，允许全局管理员在 Exposure 内管理一个部署级生效连接和至多一个待启用版本，并分别执行保存、合成验证、启用与禁用/撤销。产品配置与 OMP 开发模型无关。仅替代 [ADR-0007](0007-allow-bounded-ai-governance-draft-model-call.md)“非目标”中阻止该单连接生命周期及其设置/验证界面的部分；不授权通用模型目录、网关、多模型路由、第二调度器、多租户覆盖或新的数据出域范围。

选择不可变版本和显式生效指针，是因为修改全局环境或共享 agent 模板不能证明旧任务继续使用原模型。本决策补充既有资格、单资产核查和分析报告的连接生命周期，ADR-0015 的材料与出域限制继续适用。连接认证、任务能力验证、执行绑定和项目材料许可分别记录；前一层成功不代替后一层。启用新版本只改变新任务选择，原版本可供已固定任务继续使用；替代不等于撤销。显式撤销阻断原版本的新任务和下一次出站模型请求/工具读取，但不能声称收回已发送的数据。

## 凭据与业务事实

PostgreSQL 仍是连接版本、验证结果、生效指针和任务绑定的权威事实库；新增的专用 Secret 记录只存认证加密密文、nonce、主密钥版本和不可错配的归属身份，业务记录只保存引用。使用成熟认证加密库；密文认证须绑定部署、连接版本和 Secret 身份，篡改或移置必须失败。资格与任务指纹均纳入连接版本 ID 和不可变 Secret 版本身份；解析 Secret 时复核归属、认证解密与固定身份，引用/密文被替换或错配时拒绝旧验证，不能仅以人工 config_revision 代替凭据绑定。轮换只为新版本建立新验证，不使未撤销的旧版本任务自动换模型或失效。加密主密钥由部署独立受保护地注入，不与密文、数据库备份或 Git 同存，不复用应用 JWT/登录 Secret。备份恢复必须验证所需密钥版本和 Secret 引用能解析，缺失时 fail closed；不自动创建替代凭据。

当前仓库没有可证明的持久产品 Secret 管理器，也没有已声明的认证加密库。因此允许实现时仅为认证加密引入一个必要、受维护的库，经固定依赖和最小测试验收；不自写加密、不为此新增 Vault/第二调度平台。agent-compose 的 `secret: true` 是已有传递标记，是否隐藏持久配置与输出、是否隔离不同任务须实测，不能用标记本身证明无泄露。

仅可信 Supervisor/受限代理按任务固定版本读取凭据；模型子进程和普通 Run 参数、API、日志、审计及错误不获得原 Key。读取与审计只留非秘密身份。原环境连接只经管理员显式接管，成功前不改变现有行为；没有旧任务兼容证据不得切换现场。主密钥轮换与大规模 Secret 管理不是本片 UI 能力，所采用存储须保留密钥版本及可恢复性。

## 运行时证据门禁

复用现有 Pi、agent-compose、model qualification、模型代理、核查和分析报告执行路径，扩展任务/验证的版本绑定，不能以数据库状态或设置页面代替实际生效。先在独立数据库、Artifact、agent-compose 项目与本地固定响应端点中验证两个版本：A 任务建立后启用 B，B 新任务正确绑定，A 原任务后续 turn/恢复仍绑定 A；显式撤销 A 后其下一次调用被拒绝，B 不受影响；全部可读控制面输出与失败路径无原 Secret。

按任务注入与不可变的版本化 agent 定义均只是候选机制，未实测前不指定为已支持能力。若只能重载共享模板，或试验不能保护旧任务版本/撤销边界，则实际启用 BLOCKED，须先修订显式排空方案，不能静默弱化本决策。非客户固定响应端点只能证明传递、路由和生命周期；真实模型的核查/报告能力与语义须依正式 Issue 的材料及目的地授权另行验收。

保留 [ADR-0006](0006-allow-deployment-internal-model-qualification-endpoint.md)、ADR-0007 的端点/DNS/固定地址/SNI/无重定向/无 fallback 边界，以及 [ADR-0014](0014-allow-local-baizhi-synthetic-qualification.md)、[ADR-0015](0015-allow-bounded-synthetic-ai-business-tasks.md) 的精确合成许可。设置页不扩大全局网络或材料策略，不发送客户真实数据，不改变确定性统计、Finding、历史结果或人工确认语义。验证失败保留原生效连接；禁用模型不阻断确定性比对和历史/人工阅读。

此 ADR 固定行为与架构边界，不声称实现或隔离试验已通过。正式 Issue 钉住含本 ADR 的 Spec commit；远端发布、实际模型调用、合并、部署和关闭逐项按授权及真实结果记录，遵循 [ADR-0016](0016-pin-approved-spec-and-issue-status.md)。

# ADR-0020：NetFlow Dataset 原生端点与本地监控候选

状态：已接受（2026-09-16，维护者明确继续 EXP-EVO-01C；不代表实现/验收完成）。

依据：[Release 1 Spec 的 EXP-EVO-01C](../specs/asset-governance-release-1.md#exp-evo-01c-netflow-原生活动账与-ipv6-候选)。继承 ADR-0005、0008、0016、0018、0019；新增以下决定，不替代旧固定 Run 合同。

## 决定

- Dataset 的固定规范化 Artifact 足以支持不依赖 Resource/Run 的端点全集。使用有界只读确定性投影，固定合同/hash和源行引用；完整性/处理上限失败必须可见，不落残缺缓存、不新增资产主表。保留接受时的原始与规范化文件，不改变旧受管活动聚合。代价是每次请求扫描固定有界材料；后续确有性能证据再引入独立版本化投影缓存。
- 新增不可变本地范围/管理修订作为 PostgreSQL 业务事实。Admin 显式绑定 Dataset 到一个命名网络空间并给出 CIDR、来源位置、证据和视角；多空间无法确定时 CONFLICT。新 Dataset 重新确认。namespace 是稳定身份，不是来源 ID，也不能由 src/dst 猜测。只有明确 legacy 绑定才允许与旧 Project 空间发生受控关联。
- 候选身份由 tenant/Project/namespace/规范地址稳定推导；Dataset/范围/管理修订是评估依据，不进入身份键。资格从固定来源与修订确定性计算，不在 GET 写数据。历史范围留存，但当前撤销优先阻止新资格/关联；管理关注不能授权。
- 默认公网候选只含确认范围/PUBLIC 视角内实际出现的合格 IPv6；特殊本地地址、mapped IPv4、外部 peer、未知归属/视角有明确原因。候选只是本地分类，没有云图写权限、不表示可达/风险或已监控。
- 新绑定若无法用旧单空间比较表达，阻断新 Run；未绑定旧 Dataset 保持既有兼容行为。已固定 Run、报告、旧 Resource 身份和恢复不改；本片不把多个命名空间物化进旧比较。

## 事务与验收

复用项目锁、角色校验、预期修订、幂等恢复、审计和来源固定 URL。画像组合既有台账 reader，缺来源明确为空；不凭相同 IP 附加历史。验证以隔离合成 CSV 和明确模拟 CIDR 完成，覆盖角色/撤销/并发/失败/计数与旧报告回归；不调用外部模型、云图或扫描。

## 已接受的窄扩展：源侧分析与固定来源关联

2026-09-29 维护者批准 `EXP-NF-INT-01` 接管方案与下列差额，授权阶段 B 固定/发布正式文档和登记任务，并指定当前 OMP 会话唯一写入本阶段共享 Spec/ADR/current。精确行为与验收以 [聚焦 Spec N1–N8 / AC-NF-01–15](../specs/exposure-focus-release-1.md#exp-nf-int-01固定输入的-netflow-关联与人工复核材料) 及其 [API 附录](../specs/netflow-correlation-api-v1.md) 为准；未授予后端实施、前端接线、业务代码发布/合并、部署、真实读取或关闭许可。

| 原条款 | 最小替代与适用范围 | 历史和安全保留 |
|---|---|---|
| 本 ADR 双端原生投影、Admin CIDR/视角绑定与 IPv6 候选资格 | 增加独立 declared_source 分析上下文，绑定确切 Dataset/Hash/namespace 和逐行位置证据；不以 CIDR 资格解释位置声明，源/目的两侧证据独立 | 旧 netflow-ledger 双端投影、CIDR/PUBLIC 候选资格、旧 Run 启动和报告不变；SRC 不等于连接发起方、归属、纳管或暴露 |
| 本 ADR 与 ADR-0019 仅当前有效 legacy 确认可关联旧 Resource | 对固定客户/云图/NetFlow 来源集合，经 Admin 明确确认同 namespace 后，允许不依赖 Resource 的规范 IP 精确关联 | 默认 UNKNOWN 不能合并；当前撤销优先，新版本不自动继承证明；非 legacy 不附加旧 Resource/Run，不重编号身份 |
| 有界只读 Artifact 投影，不新增资产主表 | PostgreSQL 保存上下文修订、Analysis/Artifact 收据、固定来源选择及同空间确认、反馈修订；真实固定组件经同一 agent-compose 执行，结果有界读取 | 不复制全部端点/服务/peer 为另一份资产账；GET 无副作用，临时 SQLite 只作 scratch；失败/未完成/超限无可读半结果 |
| 旧 ManualReview 必须绑定 Resource 和已发布 Run | 增加仅组件 Analysis/task 的追加反馈材料合同；真实 actor 与原提供方声明分开，部分提交保留其他任务答案，读取固定反馈版本 | 不放宽旧 ManualReview，不新增 Finding/任务自动关闭；字段齐全仍需人工核验，不将反馈完成当事实或授权 |
| ADR-0021/0022 新云图权限、域版本、部分批次与到期清理 | 固定旧 Snapshot 或 tagged 新 IP/port 版本，引用而非持久复制云图内容，组合读取持续复核来源授权/保留 | 不借旧入口/缓存恢复到期内容，不阻塞源记录 purge，不冒称跨域原子快照，不新增实时云图方法/同步能力 |

这是独立兼容接口的窄扩展，不把新源侧语义替换进旧统计。组件固定 `netflow_processor==0.4.0` 与批准 Hash，默认 rules；完整输入、context/config/规则和输出指纹保留。外部结果自声明 Hash 不构成计算真实性，导入需原身份绑定和受控重放；不改写原 manifest 来迁就本地 UUID。

复用 Project 锁、不可变修订、幂等和原 Session 恢复。只有明确引用权威 FAILED 父记录且处理身份相同的请求可预留唯一后继；UNKNOWN/成功不自动重调度，失败历史不覆盖。初始空白反馈也有固定版本，发布与回填均受整条组件消费链的更小限额约束。代价是新增四类必要事实及有界扫描，不预建缓存、通用规则/任务框架或第二调度器。

文档审阅、组件接管、隔离合成端到端、真实三方业务验收、发布与部署分别记账。没有真实客户/云图材料仅阻塞真实三方验收；后端合成工作仍须另获实施授权。组件公开分发需权利依据，本次文档批准不推定许可证或复制二进制许可。

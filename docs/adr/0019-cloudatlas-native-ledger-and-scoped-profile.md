# ADR-0019：云图来源账、本地管理与有界地址关联

状态：已接受（2026-09-15，维护者确认继续 EXP-EVO-01B，并新增指定云图空间的真实只读 API 核验授权；实施及验收不因此自动通过）。

依据：[Release 1 Spec 的 EXP-EVO-01B](../specs/asset-governance-release-1.md#exp-evo-01b-云图原生账与综合-ip-画像)。继承 ADR-0005、0016、0018；不接受整个 EVO 路线图。

## 决定

- 原生云图账查询明确 SourceInstance、已发布兼容 Run 和完整 SourceSnapshot 下的全部 CloudAtlas Observation。它们是一条来源记录对应一条的不可变规范化投影，不经 Resource、比较、Finding 或报告样本筛选。核对快照、PULL/NORMALIZE 成功及全量行数一致后，数据库分页和统计；不新增第四份资产主表或复制原始响应。零云图行与客户非空输入可以完成原 Run，不能把空云图快照说成必然失败。
- 默认解析所选实例最近完整已发布快照并固定 URL。显式历史范围不退回 latest；后续读取失败保留上次完整快照并另示可证失败。未发布的部分记录不进入原生账；状态信息可说明已读取但尚未发布，不能把它说成完整客户可见资产。
- 本地管理以具体快照和来源记录身份保存不可变修订及审计。只使用标签和关注；不改上游值、Observation、Run 或报告。未有稳定 ID 合同，跨快照不继承管理值。父版本比较、幂等和未知响应恢复复用 01A 的语义，不复用其客户上传物化。
- 01B 最小网络范围合同是对某一云图快照与 Project 既有 legacy 地址空间的明确确认。默认 UNKNOWN；Admin 可追加 CONFIRMED_LEGACY 或 SEPARATE/UNKNOWN 修订并说明依据。快照包括源实例及连接指纹，因此新快照不会自动继承旧确认。SEPARATE 只表示不得与 legacy 合并，不意味着两个分离来源互相同空间。完整多 namespace 建模留到有明确消费者的下一片，不重编号旧 Resource。
- 画像固定客户版本、云图快照及关联修订，并列各来源事实和截至时间。仅当前仍有效的 CONFIRMED_LEGACY 可附加旧 Resource 的历史入口；撤销后旧确认可回看但不作为当前关联许可。相同文本 IP、同 Project 或同一 API 凭据均不是范围证明。来源自己的查询可在 UNKNOWN/SEPARATE 下使用。新页面不提供混合空间启动 Run 动作，也不改变旧 Run 身份或旧比较合同。
- 关联成立时复用明确 Run 的既有活动/差异与处理记录入口；没有可证关联则显示缺口，不复制历史。风险接口未接入显示未接入，不从来源 status 推导风险或监控状态。画像读取不触发 AI。

## 外部与验证边界

继续以 OctoBus 作为外部边界；仅使用已安装且固定指纹的 ListIPAssets。指定真实环境已经验证只读鉴权与分页，但一次读取不证明长期 ID 稳定、上游快照隔离或客户归属。真实响应、IP、凭据留在隔离的仓库外私有存储；模型、审阅材料、Git 与 GitHub 只接收脱敏合同/汇总。不得调用写接口、扫描或风险接口猜测。

复用原 GovernanceRun 获取落地快照，不新增同步按钮、周期任务、调度器或 SnapshotAttempt。前端访问只读已有数据；真实集成验证与纯合成权限/并发/失败测试分别记录，不将样例或 HTTP 200 当整体验收。部署、外部写入及后续候选另行授权。

# ADR-0015：允许本地合成业务材料的受限 AI 核查与分析报告

状态：已接受

范围依据：#208、#210；维护者在本轮实现会话中明确接受以下窄范围边界。#213 的报告任务仅获得边界许可，不属于 #210 的实现范围。

## 决策

保留 ADR-0006/0007 的私网生产默认。新增默认关闭、独立于 ADR-0014 四样本资格开关的本地合成业务开关，仅允许 `https://ai-api-gateway.app.baizhi.cloud/api/openai` 公网端点；沿用全部 DNS 地址验证、固定连接地址、Host/TLS SNI、禁止重定向和禁止自动 retry/fallback 的限制。不得通过降低应用安全模式启用例外。

服务端通过部署配置固定允许的合成 Project、Source 和材料内容 Hash；模型、用户请求或普通上传不能扩大该白名单。即使普通上传发生在允许的项目内，也不能自动获准出域。来源、材料或配置变化必须在下一次出域前重新验证，不以项目名称、前端参数或资格 PASS 代替材料许可。

仅允许单资产核查和一次明确 Run 的分析报告两种模型任务。核查固定 Project/Resource/已发布基础 Run/可选 Finding；报告固定 Run、材料身份、版本和截止时间。模型只获得服务端复核授权后的有界 DTO；不获得原始上传物、完整原始流量、任意历史、Artifact 文件、数据库和应用凭据。后续历史及 CloudAtlas 工具须在 #211 范围内复用 OctoBus，只读且逐次复核，当前 #210 不提前实现。

Pi 使用明确装载的白名单业务工具；禁止内建 Shell、文件访问、任意 SQL/URL、任意扩展/技能/上下文文件和外部写能力。受信 Supervisor 负责数据库读取、预算、模型代理和持久化，模型子进程与其凭据隔离。每次工具调用和返回值均复核固定范围；调用次数、累计材料字节、模型输出字节和总时长具有部署固定上限。未知 Session 保持未知，幂等重放不新建执行，失败后人工新尝试保留旧记录。

模型输出严格区分有引用事实、待验证解释、缺口和下一步；服务端复核引用身份与已成功读取的材料范围。有引用不等于语义必然正确，真实合成场景仍需验证。模型和人工说明不改变已发布 Run、统计、SourceSnapshot、Finding 或既有确定性报告。PostgreSQL 仍是唯一结构化事实库，agent-compose 仍是唯一执行调度和 Session 生命周期边界。

## 限制

本决策不授权真实客户数据出域、生产公网模型、通用模型网关、任意 Provider、后台自动执行、多 Agent、外部写回或新增调度器。Operator 执行，Viewer 只读，服务端逐项复核项目授权。测试结束后关闭专用开关并移除测试凭据；本地验收不代表远端发布、生产部署或客户验收。

# ADR-0022：有界资产批次可读，不冒充完整版本

状态：已接受（2026-09-25）。维护者已明确批准“少量数据先在正式页面可用”的有界批次合同，授权本次规格按正常CI/Review发布、固定及建立实施任务；本文随修订Spec固定后由该任务实施，不自动授权业务代码远端合并、生产部署或新增真实调用。

#253实读已证明IP与端口基本字段及单例同IP匹配可得，但来源连接中断使完整遍历之前取得的合法数据始终无法进入正式页面。新手动采集改为两域公平分配页额度、逐页轮转；每域正常到达自己的批次额度即可封存并独立发布，显式区分本批条数与来源报告total。只有确已读完请求范围才标记完整；未知、异常、撤权和指纹漂移不构成封存理由。

这是对ADR-0021“最近完整结果”阅读策略的窄扩展：默认入口可读最新正常封存批次，另保留最近仍可读完整版本入口；失败不清空旧完整结果，部分批次不覆盖历史内容。继续沿用PostgreSQL、agent-compose、OctoBus、项目/来源权限、保留期限和固定版本身份，不引入临时预览页、跨批次合并、第二调度器或源调用重试。

放弃“全部读完才允许看到任何数据”，因为它把完整性核验与可用性绑在一起；也不采用“任何失败暂存都能展示”，因为它绕过页完整性、授权复核及Session未知保护。代价是必须保存可信的正常封存依据，并在任务、版本、列表、详情、同IP匹配及最近完整版本入口中持续呈现非全量范围。

精确行为和验收见[Spec的2026-09-25修订及ACBATCH-1—5](../specs/exposure-focus-release-1.md)。旧任务按创建时合同执行，同键恢复不重调度；#250及#253历史结果不追溯升级。旧Run/报告、共享迁移、风险及其他资产域的边界不变。

## 已接受的窄扩展：主域名单域有界批次

2026-09-25维护者批准Spec中的`EXP-FOCUS-01C-ROOT`、本段窄扩展及配套字段矩阵，授权规格按正常CI/Review发布合并、固定版本建单与工作入口切换。接受范围仅为下述主域名单域合同，不改上文IP/端口行为；业务实施、业务代码远端发布及真实读取/部署仍须独立授权。

将“正常封存的有界批次可读、最近完整版本独立保留”的发布原则窄扩展到主域名单域任务。主域名使用独立能力合同与来源类型，仅一个精确只读列表方法；预算全部属于该单域，不借用或修改旧IP/端口两域的公平轮转。未封存失败/未知仍不可读，Session恢复、权限、保留及无重试边界不变。

不接受由此推导任意域选择器、通用规则引擎、自动增权或其他资产同步许可。旧来源/任务/包/Capset及历史结果保持原固定合同；源身份未证实前仍只保留域版本内记录。除此之外，ADR-0021/0022已接受条款无替代。

## 提议中的窄扩展：DNS记录单域有界批次

2026-09-26维护者选择DNS记录规格准备。本段与`EXP-FOCUS-01C-DNS`及DNS字段矩阵一并待批准；**不是已接受的DNS实施或调用许可**，不改变上文已接受的IP/端口、主域名合同。

提议复用“正常封存批次可读、最近仍可读完整版本保留”的发布原则，增加独立DNS来源类型和能力合同，只允许精确DNS列表方法，显式固定`flat=1`、valid、-id。预算全部属于DNS单域，不扩权旧Capset，不借用旧域额度，不改变Session/幂等、失败未决、权限/保留和无重试边界。

不采用flat=0聚合或实时DNS解析：前者改变记录粒度和分页合同，后者增加新的观测事实与网络访问边界；也不从名称、解析值或标签推导主域名/IP/端口关系。代价是本地仅有来源声明的DNS版本内记录，长期实体身份与跨域关系继续待核实，不以“域名相关”掩盖差额。

该候选只复用现有单域机制，不接受任意域选择器、通用资产插件框架、第二调度器或其他资产的自动同步许可。批准时由新Issue固定Spec、本段及字段矩阵的同一准确commit；新业务实施、远端生命周期、部署及真实来源读取仍分别授权，不能继承#257。

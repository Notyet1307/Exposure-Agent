## 刷新复现与修正

原 `explicitFeedbackMismatch` 把没有返回的反馈数据当作身份不匹配；外层只检查 `!isLoading`。summary 尚未返回时，feedback query 尚未启用，`isPending` 为真而 `isLoading` 为假，因此带 `feedbackRevision` 的链接可能提前报“明确反馈修订不属于当前固定 Analysis”。该条件已通过延迟请求的组件测试和真实结果只读预览复现。

现在仅在验证成功并取得反馈内容后比较身份。显式反馈验证完成前不展示结果；真正的不匹配、401/403/404/410 仍拒读，不回退 latest。已验证的固定比对若没有 NetFlow Analysis，却指定反馈修订，会明确拒读，不猜测其他 Analysis。

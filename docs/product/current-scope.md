# 当前产品范围

身份：已批准边界、推荐方案、待验证假设分栏。批准来源 [#223](https://github.com/Notyet1307/Exposure-Agent/issues/223)。行为预期见 [当前 Spec](../specs/asset-governance-release-1.md)，不在此重复。

## 谁使用

资产一致性治理人员。Project Operator 发起核查、保存人工记录、生成/编辑/确认分析报告；Viewer 只读授权范围内的事实、核查与报告；Admin 保持既有显式权限。当前交付对象是维护者可操作的本地合成验收，不是已确认的外部客户运营团队。

## 核心工作

发现差异 → 对明确单个资产做受限只读 AI 核查及追问 → 人工记录结论 → 用后续对账验证原差异是否仍在。按需手动生成以一次已发布对账为主体、结合历史与核查记录的分析报告。业务页面优先资产情况与核查进展；技术依据按需展开。

## 已批准边界

- PostgreSQL 与确定性处理是结构化业务事实来源。AI 或人工说明不改写已发布 GovernanceRun、SourceSnapshot、IPSourceComparisonFact、Finding 或既有报告中的权威内容。
- 核查由人工对单个资产发起；工具白名单、范围复核、失败保留；未知 Session 不得当成成功。
- 人工记录不关闭 Finding；NetFlow 单独不能关闭 Finding。
- 分析报告由人工生成、编辑、确认；新草稿不自动确认，也不销毁旧版。
- 本轮允许本地合成材料 + 百智云例外（见 [ADR-0014](../adr/0014-allow-local-baizhi-synthetic-qualification.md)、[ADR-0015](../adr/0015-allow-bounded-synthetic-ai-business-tasks.md)）；真实客户数据不得因此出域。
- 报告正文按资产、按 Run 归属历史，不得把一个资产的生命周期套到整组资产（[#221](https://github.com/Notyet1307/Exposure-Agent/issues/221)）。
- 当前交付等级：本地合成验收，保留已知限制。不是生产、真实客户或商业价值验证。

## 明确非目标

批量/后台自动核查或自动生成报告；自动扫描、自动处置、外部写回、分派审批闭环；人工直接关闭 Finding；新增数据源或完整通信拓扑；真实客户数据外发；客户生产验收；第二套调度/事实库；多实例 HA；把原型直接当正式实现；顺带修复既有 XLSX 兼容缺陷。

## 推荐（未批准为商业方向）

上一轮关于目标用户定位与持续运营方式的讨论仍是推荐，不是已批准产品承诺。

## 待验证假设

- 该工作流能否降低重复对账/核查成本。
- 目标治理人员是否愿意持续使用。

指标阈值未批准。环境参数（具体模型名、报告秒数、合成样例规模）见 Spec 的环境事实栏，不是本范围的产品承诺。

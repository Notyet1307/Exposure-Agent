# NetFlow bulk V1：冻结数据集的异步精确处理

状态：2026-10-13 维护者通过任务全文授权设计、实现、合成验证、分阶段本地提交，并明确授权规格发布与专属 Issue；业务代码 push/PR/merge、生产部署、真实流量及生产凭据不在授权内。基线 `05b14d52ab6d9f3b0eb54c3a7c7fcfed69bd3751`。本文件随 ADR-0026 固定；Issue 引用固定 commit 后实施。

## B1 范围与兼容

多文件、单批或累计 TB、异步批处理、低并发。容量是验证目标，不是假定每天 TB、实时查询或特定硬件。保留 50 MiB 小文件入口、0.4.0 wheel 字节/足迹与旧统计。新引擎独立源码/版本，不通过反复调用旧组件累计冒称兼容。

核心仍是客户与云图两源比对。NetFlow 仅有界辅证；失败、超时、撤销或缺失不阻断核心。保留普通最新采集范围、固定历史、租户/项目隔离和当前 Context 撤销。源列、端口、peer 不证明本方归属、监听、会话、互联网可达。所有未证明条件保持 UNKNOWN。无逐条模型调用、无真实数据外传。

## B2 接入与不可变身份

服务器受控来源注册绑定 tenant/project/source 与固定挂载根；API 只收来源 ID、ready manifest 身份、配置及有界文件清单，不传任意路径、不上传 TB。根目录只读挂载；拒绝绝对路径、父路径、符号链接、非普通文件、重复文件身份及越界。服务端封存命令从已关闭的输入创建独立快照副本，流式计算摘要，fsync 后原子发布 ready 标记；标记含完整 SHA256、字节数、成员身份、编码、schema 和冻结协议版本。使用隔离、不可由上传用户写入的快照目录。仅文件名/大小稳定不构成冻结。

首次 worker 接入仍核对字节摘要、类型和身份，处理中漂移失败。已验收不可变身份允许解析前任务幂等；不信任客户端自报摘要跳过校验。API 限制 manifest 字节/文件数，更多文件用多个有界批次；每个逻辑批次完整精确处理。版本化 dataset manifest 包含租户、项目、来源、namespace、Context 引用、文件身份/大小/摘要/编码/schema/行数和分片状态；成员、分片状态用 PostgreSQL 多行保存，结果每页不复制完整清单。

CSV/TXT 使用 CSV 逻辑记录解析，支持引号换行；不按任意字节拆输入。明确编码，不悄悄替换乱码。初版只接受未压缩 CSV/TXT；拒绝 gzip/zip 等压缩输入，后续支持须另加解压字节预算和恢复合同。每个字段、逻辑记录与批次均有限额，超限失败不截断成功。

## B3 三类不同合同

### 文件及任务幂等

同 tenant/project/source 和冻结完整清单身份形成 dataset 身份。成员按稳定文件身份排序；重复提交命中同任务/结果；改变条件创建新 analysis。相同文件多次出现在清单中拒绝，不重复累计。任务重试复用已提交的标准化分片与计数，不能把中间计数相加重复记账。

### 记录去重 `bulk-export-row-v1`

作用域仅一个冻结逻辑 dataset 的全部成员，跨文件/分片/顺序/重试一致；不承诺跨 dataset 或跨日增量去重。完整 canonical key 精确比较，哈希只作索引/分桶，不能单独决定相等。

规范地址合并 IPv4 mapped IPv6，时间按声明时区转 UTC，协议/端口/计数按类型规范。键保留双端地址/端口、协议、开始/结束时间、双向字节/包数、TCP flags、exporter、采集点、observation domain、采样模式/率、NAT 字段及其他原始列的确定性表示。不同采集点、时间、peer、协议、采样不能被相同 IP 合并。

仅时间区间有效且 exporter、采集点、observation domain、采样身份完整时，合并完整键相同的导出记录。任一身份或时间缺失时在 key 中加入稳定文件身份与逻辑行号，保守保留每条记录；不得补造字段。即使合并，也只声明相同导出记录，不证明同一真实网络事件。确定性代表记录为文件身份和逻辑行号最小者，所有原始来源仍在标准化证据层可追溯。原始快照不删；旧结果不重算。

### 业务聚合与计数

顺序：解析 → 有效性 → 过滤 → 全 dataset 精确去重 → 业务聚合。`raw = invalid + filtered + retained`，`retained = unique + duplicate`。invalid 是不可用网络事实，不包含业务过滤；filtered 只统计有效但不满足配置的记录；duplicate 只统计 retained 中被当前去重策略合并的副本。每个计数固定 policy/filter/context/result version 与分母。

聚合以 IP、协议、源端口、角色和观测窗口为键；peer 独立计数。流记录数不是会话数，采样值不是完整真实流量。完整记录数、保留证据样本数、遗漏数分别返回；样本按稳定来源顺序选最多 20 个，不对所有 peer/source refs 做 list/string_agg。无 Python 全局 set/dict/pandas 保存全量记录或键；有界 batch 允许。CIDR 匹配采用合并地址区间/二分或等价非逐行遍历全部网段方法，IPv6 同样成立。

## B4 引擎与复用

独立 bulk worker 经现有 agent-compose 启动；PostgreSQL 保存任务、lease、heartbeat、检查点、配置身份和查询投影。DuckDB 是可重建的外存计算工作区，不是第二业务事实库或调度器。不可变 Parquet 分片保存标准化明细、来源引用、invalid 与原始字段；限制 batch/分片/row group 大小，不按 IP 创建目录。

DuckDB 显式 memory_limit、threads、temp_directory、max_temp_directory_size，禁自动扩展安装/网络访问；容器/进程另设 RSS/CPU/磁盘预算。测量整个进程 RSS，不把 buffer manager 限制称硬上限。磁盘不足、quota/OOM/超时均受控失败、保留已提交状态。重型 distinct/sort/aggregate 分阶段物化，必要时完整键分桶；跨分桶归并必须保持精确。

过滤变更复用标准化 Parquet，列/时间裁剪；不再次解析 CSV。缓存键包含 schema、引擎、去重/规则、完整 filter、Context 身份和输入身份，兼容性变化必须失效。Python 3.14 保持；锁定实际可用的 macOS arm64、Linux arm64/amd64 依赖，镜像验证单独记录。

## B5 恢复与发布

状态为待执行、运行、取消、失败、成功；任务/analysis 以既有公共状态兼容映射，内部明确阶段。使用 PostgreSQL 原子 lease 与 fencing token，低并发上限，定期 heartbeat。旧 worker lease 丢失不能写 checkpoint/投影或发布。取消可轮询、终态不可变；重试显式申请新执行 lease，agent-compose 仍管理 Session 生命周期。

分片先写 task/attempt 私有临时文件，flush/fsync、读回 schema/行数/摘要，原子 rename，再持有有效 fencing token 提交 checkpoint；数据库仅引用已校验文件。崩溃在 rename 后、checkpoint 前时，孤立文件不可见；恢复核验后采用或重做，不叠加计数。已提交分片复用；正在解析的单个超大输入可能从文件头重读，跳过已校验的逻辑记录区间，不声称任意字节断点恢复。

最终发布先验证所有成员完整、分片计数守恒、汇总与投影完整，再同一 PostgreSQL 事务提交结果身份与可读状态。投影可分批 staging，但未发布 analysis 不可读。发布失败保留可重试 staging；不得暴露半成品。最新指针使用提交序号/冻结输入顺序防止旧任务迟到覆盖新正确结果；固定历史仍可读取其成功版本。发布时重新检查权限、项目状态与最新 Context 撤销。

## B6 结果仓储与业务接入

版本化 repository 分发：旧结果沿原 bundle 完整性路径，bulk 使用 PostgreSQL 摘要/对象投影和列式高基数 peer/定向证据。对象及地址/协议/端口索引批写，计数用 bigint；禁止所有原始流入 PostgreSQL 或巨型 JSON。按实测高基数评估投影。

bulk 所有列表服务端过滤/稳定排序/分页，优先绑定完整身份和 filter 的 keyset cursor；旧 offset 接口保留兼容但不能先全量加载。绑定 tenant/project/scope/dataset/analysis/policy/context。普通列表不访问/hash 原始文件，只核对版本绑定和发布校验回执；只读封存目录、受控写者和显式失效/校验机制形成信任边界。定向证据只读命中分片并验证其校验值；发现漂移置失效且拒读，不回退旧内容。

当前观测页面与 V2 辅证接入同仓储，固定历史不漂移。旧 ledger/旧 V1 全量关联明确拒绝 bulk，不能隐式扫描。新 bulk 不冒充 0.4.0 的 review/feedback 分析能力；明确其独立规则/材料能力和未知条件。已完成结果无每五秒无条件重取；进度可轮询，轻量权限/Context 校验确保撤销及时清空缓存。

## B7 验收与交付

仅合成或明确授权脱敏输入。固定种子生成器可控字节/行宽、IPv6、重复、唯一对象/peer、高热点与多文件重叠；不以全相同行/异常压缩率冒充容量。

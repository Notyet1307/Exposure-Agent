## 已批准要求

### 工作流

治理人员以 IP、发现类型和业务状态识别问题。看到各来源观测、数据时间和活动线索后，对明确的单个资产或发现手动发起 AI 核查；可在同一 Project/资产/已发布基础 Run 范围内追问。保存人工结论；该结论尚不代表 Finding 已解决。后续成功且兼容的对账验证原差异已解决、仍存在或证据不足。可手动生成一次对账的分析报告；无核查时如实说明缺口。Viewer 只读，不能触发模型、写入人工结论或确认报告。

### 权威事实与时间

PostgreSQL 与确定性处理仍是结构化业务事实来源。AI 或人工说明不更新 GovernanceRun、SourceSnapshot、IPSourceComparisonFact、Finding 或已有 GovernanceReport 的权威内容。核查固定 Project、Resource、基础已发布 Run，以及相关 Finding（若从发现项发起）。追问延续该范围，不静默切到 latest。新的只读查询记录查询时间与引用身份，不得覆盖原 Run 快照或混入原 Run 统计。未执行、未成功或越权的查询不能产生肯定性新事实。失败记录可引用为局限，不能当作成功 Evidence。

### AI 核查

Pi 执行受限模型会话，模型只调用白名单工具；至少包含明确范围内的系统事实/历史读取和既有 CloudAtlas 的 OctoBus 只读能力。每个工具参数和返回值由服务端复核授权与范围。模型不得获得数据库凭据、应用 Secret、任意 Shell/SQL/URL、Artifact 原始文件或外部写能力。核查和每轮追问有可观察状态与部署固定的工具/数据量/时长上限。未知 Session 不得解释为成功或自动另开重复执行。请求重放保持幂等；失败后的再次人工尝试保留原失败记录。不得以自动换模型/Provider 或无界 retry 强行完成。输出分清事实、解释、缺口和建议。引用检查验证身份和范围；有引用不等于语义正确。

### 人工记录与后续验证

人工记录保留作者、时间、关联对象、基础 Run、结论及待验证事项；更正追加版本并保留原记录。验证只回答原一致性差异是否被后续事实解决。关联同一 Project/Resource 的后续成功且兼容 Run：满足既有确定性关闭规则才显示已验证解决；仍存在差异显示未解决；不足以判断则显示证据不足/待验证。NetFlow 的 ACTIVE、零记录或缺失均不单独关闭 Finding。已发布的后续 Run 与验证结果不可重写；再出现失败 Run 时保留原成功验证身份。

### 分析报告

用户手动生成/更新草稿，以一个明确 Run 的完整确定性摘要为主体，可读取有界历史与已保存核查/人工记录。模型不自行汇总权威总数，不编造业务归属、严重性、因果或已完成动作。保存 AI 原稿与人工编辑；人工确认是独立动作。统计、身份和引用不可当作随意修改字段。新材料出现时，标题/主要操作区醒目标明未纳入此版本，并提供生成新草稿入口；完整旧版本保持可读。新草稿不自动确认，也不自动覆盖已有草稿/确认版历史。

可读性修订（#220）：正文简体中文、结论先行、短段落与业务语言；固定材料和引用中保留完整追溯身份；统计只复述权威事实；区分当前差异、历史积压及无数据/零风险。

历史归属修订（#221）：正文按资产、按 Run 说明不同轨迹。不得把某一个资产的生命周期套用于整组资产。结构化引用合法不能代替这项语义。截断历史须标明缺口。

### 页面与权限

默认阅读顺序：资产情况 → 核查进展/验证 → 分析报告。“查看依据”保留技术追溯。列表主标识为 IP、发现类型等业务信息；完整 ID/Hash 可复制，短显示不改变引用身份。窄屏与键盘可用。Operator 执行核查、记录和报告编辑/确认；Viewer 只读；Admin 保持既有显式权限。每个服务端操作复核项目授权。保留简体中文/英文、明确的空/加载/失败状态，以及确定性报告的独立可用性。

### 实现与验收约束

正式实现必须运行真实 Pi、只读工具、agent-compose 和数据库；模拟原型不能代替功能验收。真实客户数据不得因此出域。复用现有业务 reader、项目授权、报告校验和 agent-compose 生命周期。

## 明确非目标

- 批量/后台自动核查、对账后自动生成 AI 报告、独立周期汇总报告。
- 自动扫描、Retry/Rerun 作为本 Spec 新能力、外部写回、自动处置、分派审批/工单闭环或人工直接关闭 Finding。
- 新增 CMDB/扫描器等数据源、完整通信拓扑或未经事实支持的业务归属。
- 真实客户数据向百智云外发、客户生产验收、第二套调度/事实库、多实例 HA。
- 将原型直接合入正式入口、未要求的新导出、顺带修复既有 XLSX 兼容缺陷。

## 环境事实（不是产品承诺）

以下只描述已发生的本地验收环境，不升格为永久产品保证：

- 验收曾使用 `grok-4.6` / Responses。
- 该次本地报告执行上限从 120 秒改为 300 秒；其余预算与权限未放宽。
- 大样例曾为 300 个合成 IP、10000 条流量、5 轮业务演变。
- 运行栈与模型绑定是部署配置，随环境变化。

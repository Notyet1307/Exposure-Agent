# V2 阅读修复与 AI 解读报告

状态：候选，待维护者批准和 Git 固定版本任务衔接。2026-10-08 的“按照 prompt 完成我们 v2 目标”授权本轮接管、候选合同及必要核验；不将其写成新 ADR 已接受或远端发布许可。输入为维护者提供的 `Exposure_V2_AI_Review_and_Codex_Prompt_20261008.md`；接管基线 `5c46d44a753db4f39479640d7f07e0b3909f85df`。行为以批准后固定的本文件为准，附件和 Issue 不各自维护第二份合同。

## 1. 目标与阶段

新用户从固定 V2 结果直接阅读可追溯的 AI 解读报告，无需旧 GovernanceRun。报告、结果页摘要复用同一次生成和同一份固定材料。AI 不可用时核心核对、确定性字段和来源阅读继续可用。

| 阶段 | 本轮交付 | 独立验收与依赖 |
| --- | --- | --- |
| A：阅读修复 | F1 首次辅证失败及显式 GET 重试；F2 IP/port 分域固定版本和返回；业务字段分组；AI 设置独立入口及准确可用性 | 单独实现、提交、验收；不依赖 B/C 或模型调用 |
| B：报告纵向切片 | 固定 V2 材料、显式生成、同报告摘要、全文、原稿留存、人工修订/确认及可用打印 | A 后独立实现、提交、验收；无 Run、无 NetFlow 也可生成 |
| C：地址解释 | 固定同一结果和地址的事实、可能解释、缺口、核实建议 | B 合同与材料适配器复用；不阻塞 B，不读取任意地址/历史 |

旧 Run、报告、核查、V1 关联、来源 18 类独立查询继续原固定合同。没有默认多 Agent、自由聊天、来源同步、扫描、写回、期限延长或历史清理。本期不增加 DOCX/PDF 下载按钮；打印支持浏览器保存 PDF。Pi Durable 与跨版本变化解读另行立项，本期不采用、不试验。

## 2. 阶段 A 行为

1. 辅证状态区分未请求/加载、读取失败、明确无绑定、固定可读绑定、失效。错误优先于查询参数缺失；HTTP 403 显示拒读，500/超时显示失败，均保留 C+A。显式重试只读同一 result 和同一固定 binding（未解析时仅重读其 current 元数据）；成功后固定 ID 或 `none`，失败不得改为无绑定或 latest。
2. IP/port 各自存在即提供本次固定资料入口；只存在一个域时只显示该域。入口传其确切版本及同项目受验证返回参数；返回保留 result、binding、分类、页码、IP、排序、地址及依据页。发布 port-v2 不改变 R1 的 port-v1 入口。
3. 地址详情按客户声明、云图观测、NetFlow 佐证、限制与来源展示确定性业务字段。复用既有字段组件/白名单；缺值为未提供，复杂原文和来源身份放技术详情。客户端口、云图端口、源侧观测端口不混称监听事实。
4. 复用部署级 `/ai-settings` 和连接生命周期，放系统设置可达入口，不能命名为项目私有连接。生成按钮分别表达未配置、未启用、资格未验证、材料不可用、权限不足和可提交；状态读取失败不宣称就绪。打开设置不写配置、不做资格验证或模型请求。

## 3. 报告身份、API 与持久化

新增显式 V2 请求合同，不把 result_id 写入 run_id，不制造 GovernanceRun。优先扩展现有 AnalysisReport 生命周期及单表，通过新增 subject discriminator、nullable 旧 run_id、确切 core result/binding 外键和排他约束表达：

- 旧 subject `governance_run`：原请求、非空 run_id、v1 输出和原历史不变。
- 新 subject `core_comparison_v2`：固定 tenant/project/result_id；`supplement_binding_id` 是确切可读 ID 或显式 null（不使用），禁止省略后在执行中解析 latest；可选 `address_key` 仅用于 C。
- 固定 `audience=management|operations`、`language=zh|en`、`material_contract_version=v2-ai-material-v1`、`template_version=v2-ai-report-v1`（C 为独立窄模板）、实际 model connection version/config fingerprint、material SHA-256、创建 actor、预算和幂等请求摘要。服务端固定受支持版本，不信客户端声明资格。

精确实现选择使用现有 AnalysisReport API 的 V2 入口，保留旧请求兼容。候选路由为项目级 `/analysis-reports/v2` 创建/列表/就绪、现有 report ID 读取/原稿/修订/确认及 operation key 恢复；所有返回明确 subject 和 output contract。读就绪、轮询、刷新、分页只 GET。地址解释复用相同任务类型及唯一白名单工具，通过受约束 address_key 缩小材料，不另建调度器。最终 OpenAPI 和客户端由仓库工具生成；路径等义微调记入实施回执。

新增迁移只追加。保留全部旧记录/材料 Hash/原稿/身份；合法组合由数据库约束和同 tenant/project 外键保护。请求幂等锁/唯一约束沿现有事务；请求摘要包含 audience/language/subject/模板。相同 key 同请求恢复原任务，异请求冲突。未知网络结果先查原 key，不另开模型任务。模型失败保留独立失败版本，确定性结果和旧报告不变。

现有 `protect_analysis_report()` trigger须按subject分支：governance_run保持完全相同的已发布GovernanceRun校验；V2数据库分支校验同tenant/project的已发布CoreComparisonResult和确切绑定关系，应用服务再逐次调用core/binding reader复核完整性、权限、期限。不得删除或放宽旧检查、不可变材料、状态转移、预算及确认保护，不回填/改写旧材料。Viewer仅在subject当前可读时阅读；Operator才可创建、编辑、确认，设置管理继续原Admin边界。

人工编辑追加保存修订及编辑人/时间，不覆盖模型原稿或此前人工修订。保存和确认是两个动作，按预期 revision 做 CAS；冲突拒绝，不覆盖另一人的正文。确认固定报告修订，不确认资产归属、漏洞或处置事实。已确认版不再编辑，修改需新修订/版本，不能静默改正文。

V2人工编辑仅改解释/假设/缺口/建议及摘要中的非事实正文；subject、fact/evidence refs、claim type、重点地址、权威字段及模型原稿不可编辑。新增人工文字明确标记作者/时间和未独立核实状态；不能把编辑入口变成绕过结构和数值校验的通路。

## 4. 固定有界材料

服务端调用现有 core result reader 和确切 supplement reader 重新鉴权、期限、同范围及完整性。模型只获得 DTO，不得获得数据库、SQL、Artifact、任意 URL、文件目录、最新资产接口或原始 NetFlow。C+A 核心材料必需，NetFlow 可选；请求明确选择的辅证拒读时拒绝该请求，不静默变为 null。

材料包括项目/网络空间/可比范围、result ID/生成时间/规则及输入指纹、客户 upload/revision/profile/生效时间、IP/port 各域版本/采集时间/覆盖、程序生成的权威全集/三类计数及限制。核心部分覆盖时缺失的分类数保持 null，不能生成完整核对结论。

默认差异样本最多 20 个地址，按三类确定性取样且去重，保留 address_key/分类/两侧记录数和固定来源引用。每地址原记录投影有独立上限；累计材料大小沿部署预算，上限命中保留 sampled/eligible/omitted/count/stop_reason，不能称已逐条审阅全集。模型不可重算或估计全量比例。C 只取同结果确切地址，缺地址拒绝。

辅证包括固定绑定 ID/Analysis/Context/namespace/资格/valid_until、已有受控聚合和有界来源引用。观测窗口只用真实受控窗口，当前缺值则 UNKNOWN/NOT_PROVIDED 和原因；上传/处理/绑定时间另列，不推导最近活动或同时性。NetFlow 不改变核心统计，独有地址只是补充线索。未经既有合同固定的管理备注/人工核实不进入首片；原始来源备注即使投影也只是不可信数据。

每个 fact/evidence ref 包含 subject 范围与确切版本；有引用不等于语义正确。原始标题、banner、证书、备注及历史 AI 文本都不是指令。新材料 hash 或资料更新只提示可新生成，不改旧材料和正文。

## 5. 输出与确定性展示

V2 新结构至少含 `summary`、`sections[]`、`claims[]`、`priority_cases[]`、`limitations[]`。旧四段输出不重写。事实、解释、假设、缺口、建议用不同 type。每个事实和重点对象必须有当前 subject 中的 fact/evidence refs；重点对象只选材料内地址，核实建议说明对象、缺少的依据及什么新证据会改变判断，归属不可靠则不指定负责人。

默认六章：本轮核对结论、主要差异及业务含义、建议核实的重点对象、NetFlow 佐证与限制、下一步建议、数据范围与证据附录。管理/运营模板仅改变组织与解释深度，语言不改变事实。结果页本轮 AI 解读从同报告读取短结论/重点/建议/限制，查看全文保留回到固定结果的入口。

权威数字、比例、统计、分类、版本、时间与事实句由确定性 renderer 依据 fact refs 填充；模型选择材料内 refs、提供分类型解释和核实建议，不接收可覆盖统计的字段。Schema 禁止额外字段/不支持类型/地址/引用，校验跨项目、跨版本、分类、数量和样本范围；不得仅按 citation ID 存在判定语义真实。未知窗口、差异不等于漏洞/违规、建议不等于已处置等固定限制必须由服务端插入。

合成负例中的伪造数字、未知窗口虚构最近活动、无依据严重性/漏洞/违规或已处置断言必须被拦截或进入明确失败状态，不能直接展示为事实。自由解释不能由字符串规则证明全部真实；涉及高影响判断的正文保留待人工核实标记，独立业务审阅及显式人工确认不可省略。测试只证明其覆盖样例。

渲染使用已有 React 文本/受限结构，不执行模型 HTML、脚本、带外资源或任意链接。打印真实正文、确定性统计、来源/范围/限制与版本，隐藏按钮/侧栏并处理分页。无报告/未就绪显示真实引导，模型失败显式失败并保留确定性信息，不展示示例成功。

## 6. 安全、生命周期与执行

复用现有 model connection/qualification、agent-compose、Pi runner、受限代理、审计、预算和 `read_report_material` 唯一工具。无 shell/read/write/CodingTools、任意联网、自动 retry/fallback、多 Agent。每次工具、模型转发、恢复、结果保存复核固定材料 hash、actor/project 权限、连接版本、资格及累计预算。

报告所有列表/摘要/原稿/正文/引用/修订/确认/打印以及模型运行上下文均受固定 C/A 和选择的辅证当前读取资格约束。辅证过期或撤权时，混合依赖首片整份 AI 报告拒读，只返回脱敏身份/不可读状态；C+A 结果继续可读。重新生成仅 C+A 必须显式新请求、新报告身份，不改已确认版。任一读取失败不算没有资料；晚到响应不能复活清除内容。

缓存按 actor/project/result/binding/report/revision 分离；注销、切换、403/410、辅证截止清除正文/摘要/打印和本地编辑内容。runner 不复用过期 transcript 中的业务材料；控制面不能暴露原文，无法证明会话材料不再可读则拒绝含辅证生成并记录具体 blocker，不降低 reader 边界。取消/未知/超时按原真实终态表示，不用关浏览器假装后端已取消。已下载文件无法远程收回；打印前说明用途和实际辅证截止，不承诺撤回。

新 [ADR-0025 候选](../adr/0025-v2-ai-report-materials.md) 只扩展受限报告的 V2 subject/材料范围，默认私网目标和现有网络保护不变。本轮验证只在独立 PostgreSQL、文件存储、端口与执行器使用非客户黄金集和本地固定响应 Provider/临时凭据；不调用既有真实模型或来源、不读取现场 Secret、不泛化 ADR-0015 公网例外。真实模型语义单独 NOT_RUN，不能用 fake Provider PASS 代替。

V2合成许可使用独立的判别manifest项，至少精确绑定 project/subject kind/result ID/core input hash、binding ID/revision/valid_until或明确null、material SHA-256及真实source identities；旧run许可项不能匹配V2，不能用空sources绕过。每次出站/工具/恢复均比较固定许可并重新检查当前读取资格，旧hash仍命中不代表过期材料可读。

## 7. 验收

每条记录候选 SHA、固定 Spec commit、命令/操作、证据及 PASS/FAIL/BLOCKED/NOT_RUN。阶段可独立交付；代码审阅的 Standards/Spec 两轴与业务审阅分开。

| A-01 | 无 binding 首次元数据 500/403/超时真实错误；核心保持可读，显式 GET 重试，零写入 |
| A-02 | IP-v1/port-v1 双域，随后发布 port-v2；本次入口仍固定 v1，往返完整上下文 |
| A-03 | 客户/云图/流量/限制确定性字段、缺值、原文与技术身份可读；三宽度、键盘、双语、文本安全 |
| A-04 | 设置独立可达、现有部署级权限及连接合同不改；各类不可生成状态准确且零自动调用 |

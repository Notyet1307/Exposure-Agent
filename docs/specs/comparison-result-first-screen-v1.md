# 固定比对结果首屏说明两类地址差异

拟入库：`docs/specs/comparison-result-first-screen-v1.md`。探索基线 `7bb5ac127df2cb155f16577e28c504150c0c2141`；这是现状版本，不是新 Spec 的提交。

**目标与范围**：打开一份已有的 V2 固定比对结果，不操作即可回答「本次哪两类地址需要核查、各有多少」，并能直接查看对应地址。只调整核心计数区域和既有分类入口；保留资料顺序、默认的全部地址列表以及“更新比对”主操作。

| 编号 | 可观察的验收条件 |
|---|---|
| AC1 首屏结论 | 正常打开可读、覆盖完整的固定结果。在 1280×844 与 390×844 两种视口，初始页面无需滚动、展开或筛选即可读完两个方向及计数。示例（合成数据）：「3 个云图地址在本版台账未登记；另有 1 个台账地址在本批云图未观测。」沿用页面当前语言。 |
| AC2 数字口径 | 两数是这份固定结果全量的 `cloud_only`、`customer_only`，只取同一结果已鉴权的摘要，不受地址筛选、页码或可选 NetFlow 辅证影响。覆盖完整且确为零才显示 0；覆盖不足、不足以判定时明确显示差异未知，不把已知记录当全量。 |
| AC3 查看明细 | 主动点任一方向，查看同一结果对应分类的全部地址，从第一页开始。清除与“查看此类全部地址”冲突的 IP 筛选，保留结果 ID 和既有辅证绑定；返回后仍是原固定结果，不切最新、不生成或更新比对。 |
| AC4 失效与权限 | 核心摘要拒读、已失效或身份不匹配时，不显示旧数字或提供基于旧数据的入口；若仅辅证不可用而核心摘要仍可读，两类核心差异不变。 |

**后端契约**：复用固定结果的 `GET comparison-results/{id}/summary` 和 `/addresses`。不新增接口或数据表，不修改比对算法、权限、旧 Run/V1、输入页或报告。差异只表示两份资料的差别；“未观测”不代表下线，不生成风险分或 Finding。
